## The Seed: IME v2.4 Core Features

### What Already Exists

Based on Precog's IME specification, the seed contains:

#### Technical Foundation
- **Platform**: HTML5 Canvas / JavaScript (client-side execution)
- **Renderer**: Pixelated Retro (GBC-style) with `image-rendering: pixelated`
- **Resolutions**: 
  - Retro: 160x144 (10:9)
  - Modern: 256x144 (16:9)
  - Toggleable via 'F' key
- **Color Palette**: Fixed 10-Color Palette (GBC_COLORS) optimized for sprite/background contrast
- **RNG Algorithm**: `xmur3a` & `sfc32` for reproducible seed-based generation
- **Persistence**: HTML5 Local Storage (stores soulSeed, gold, inventory, vault)

#### World Generation System
1. **NEXUS HUB** (Seed: 'NEXUS-HUB-001')
   - Central resource management hub
   - Starfield parallax background
   - Gold conversion system
   - Vault management (V control)

2. **Dungeon Worlds**
   - Map Size: 64 x 36 tile grid
   - Room-based generation via Drunkard's Walk variant
   - Minimum 2-tile thick wall border (boundary fix in v2.4)
   - Unique worlds from System.seed

3. **Portal Jumping Mechanism**
   - Access different seeded worlds
   - Each seed generates unique persistent dungeon

#### Current State
- ✅ Basic engine structure exists
- ✅ Seed-based procedural generation working
- ✅ NEXUS hub concept implemented
- ✅ Local storage persistence
- ⚠️  Partially debugged and tested
- 🔄 Ready for evolution and expansion
