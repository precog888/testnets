# Testnets Repository

## Overview

This repository serves as a workspace for testing and developing AI agent workflows, particularly focusing on iterative development and debugging processes.

## Purpose

The primary purpose of this repository is to:
- Test and refine AI agent collaboration patterns
- Develop structured approaches for step-by-step iteration
- Document best practices for human-AI interaction
- Provide templates and frameworks for controlled development workflows

## Current Components

### RecursiveAgent
Located in `.github/agents/my-agent.md`, this is a JavaScript class framework for:
- Recursive debugging and learning
- Pattern recognition and failure analysis
- Decision-making with memory and semantic learning
- Session state management for agent handoffs

## Working with This Repository

### Step-by-Step Approach

We prioritize a **controlled, iterative approach** where:

1. **Small Changes**: Each change should be minimal and focused
2. **Explicit Approval**: Wait for user confirmation before proceeding
3. **Clear Communication**: Always explain what will be done before doing it
4. **Transparent Process**: Document reasoning and alternatives
5. **User Control**: The user drives the direction, AI assists

### Collaboration Workflow

```
1. User describes need or problem
   ↓
2. AI proposes specific, small step
   ↓
3. User reviews and approves/modifies
   ↓
4. AI implements only approved changes
   ↓
5. Results are verified together
   ↓
6. Repeat for next step
```
