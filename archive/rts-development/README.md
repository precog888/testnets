# RTS Development Archive

## 📚 Conversation History Storage

This directory stores .rts (development conversation) files that document the complete evolution of the IME project.

## 🎯 Purpose

These archives serve as the **project memory** - capturing:
- Design decisions and rationale
- Technical problem-solving discussions
- Feature iteration history
- Bug fixes and their solutions
- Evolution of the vision

## 📁 How to Add Your Archives

### For Precog:

1. **Export your Gemini 2.5 Flash conversations:**
   - Save as .txt or .rts format
   - Include timestamps if possible
   - Keep entire conversation threads intact

2. **Place files in this directory** using this naming format:
   ```
   YYYY-MM-DD_topic-description.rts
   ```

3. **Example file names:**
   ```
   2025-11-05_pokemon-bounce-initial-test.rts
   2025-11-05_dungeon-generation-drunkard-walk.rts
   2025-11-06_nexus-hub-24-controls.rts
   2025-11-06_portal-mechanics-discussion.rts
   2025-11-07_2-tile-boundary-fix.rts
   ```

## 🤖 How AI Agents Will Use These

When you upload .rts files, AI agents will:

1. **Read and analyze** the conversation history
2. **Extract technical details** (algorithms, data structures, design patterns)
3. **Understand your design philosophy** and preferences
4. **Identify what worked** and what didn't
5. **Preserve your original vision** when making enhancements
6. **Avoid repeating past mistakes** or already-solved problems
7. **Build on proven concepts** rather than reinventing

## 🔍 What to Include in Archives

**Essential Conversations:**
- ✅ Feature design discussions
- ✅ Technical implementation details
- ✅ Bug fix sessions
- ✅ Performance optimization
- ✅ UI/UX refinements
- ✅ Algorithm explanations
- ✅ Testing and debugging

**Less Critical:**
- ⚠️ General questions/clarifications (unless they reveal design intent)
- ⚠️ Small typo fixes
- ⚠️ Conversations with no code or design content

## 📊 Archive Analysis

Once archives are uploaded, the Documentation Agent will create:

1. **Timeline** - Chronological feature development
2. **Technical Index** - Key algorithms and patterns
3. **Decision Log** - Why choices were made
4. **Feature Map** - What exists, what's planned, what was abandoned
5. **Lessons Learned** - Problems encountered and solutions
