## Quick Reference

### Pace Control

| Mode | Description | Best For |
|------|-------------|----------|
| 🐢 Extra Careful | See every change before made | Learning, critical changes |
| 🚶 Step-by-Step | One change at a time with brief explanation | Most work (recommended) |
| 🏃 Trust | Multiple related changes approved together | Routine tasks, high trust |

### Essential Commands

**To slow down**:
- "Slow down"
- "Smaller steps please"
- "Show me every change"

**To understand**:
- "Explain why"
- "What are alternatives?"
- "Show me the code"

**To control**:
- "Stop" / "Wait"
- "Different approach"
- "Let me test first"

### Key Principles

✅ Explicit > Implicit
✅ Small > Large  
✅ Clear > Fast
✅ User Pace > AI Pace
